# 영상 얼굴 모자이크 웹앱

영상 속 얼굴을 자동으로 찾아 모자이크하고, 새 MP4 파일로 저장하는 웹앱입니다.
**모든 처리는 브라우저 안에서만 이뤄지며, 영상과 얼굴 정보를 서버로 보내지 않습니다.**

학교 행사·수업 영상을 올리기 전에 학생 얼굴을 가리는 용도로 만들었습니다.

## 주요 기능

- **자동 얼굴 찾기**: 영상을 열면 바로 얼굴을 찾아 모자이크합니다.
- **영역 지정**: 사각형·다각형으로 가릴 곳을 정하고, 교사 자리처럼 가리지 않을 곳은 제외 영역으로 둡니다. 영역마다 적용 구간도 정할 수 있습니다.
- **검토·수정**
  - 한 프레임씩 넘기기, ‘다음 모자이크’로 모자이크가 새로 생기는 곳만 건너뛰며 확인
  - 놓친 얼굴은 ‘얼굴 추가’로 한 번 표시하면 앞뒤 프레임이 자동으로 채워짐
  - 잘못 들어간 모자이크는 ‘가림 삭제’로 이어지는 구간까지 한 번에 지움
  - ‘얼굴이 아닌 것 거르기’로 옷깃·무늬 같은 오검출을 줄임
- **긴 영상 나누기**: 개수나 용량 기준으로 조각내어 저장합니다. 중간에 멈춰도 끝난 조각은 남습니다.
- **사양 점검**: 앱을 열면 이 컴퓨터로 처리할 수 있는지 먼저 확인합니다.
- **오프라인 사용(PWA)**: 한 번 열어 두면 인터넷이 끊겨도 같은 주소로 쓸 수 있습니다.
- **프로젝트 파일**: 영역·설정·직접 추가한 얼굴을 `.json` 으로 저장했다가 다시 불러옵니다.

## 사용 환경

- 데스크톱·노트북의 크롬·엣지·웨일 최신 버전 (휴대폰·태블릿에서는 처리할 수 없습니다)
- 바로 열리는 형식: MP4·MOV·WebM
- AVI·MKV·WMV·MTS 등은 형식 변환 기능을 따로 설치해야 열립니다([맨 아래 안내](#직접-설치해야-하는-항목-라이선스-안내) 참고)

## 사용 방법

1. **사양 점검**: 앱을 열면 약 10초 동안 이 컴퓨터로 처리할 수 있는지 확인합니다.
2. **영상 불러오기**: 파일을 끌어다 놓거나 눌러서 고릅니다. 불러오면 얼굴 찾기가 자동으로 시작됩니다.
3. **영역 그리기(선택)**: 그리지 않으면 화면 전체가 대상입니다. 얼굴을 찾는 동안에도 그릴 수 있습니다.
4. **검토**: 미리보기에서 확인하고, 빠진 얼굴은 추가하고 잘못된 모자이크는 지웁니다.
5. **저장**: ‘모자이크 영상 저장’을 누르면 `원본이름_mosaic.mp4` 로 저장합니다. 원본 파일은 바뀌지 않습니다.

> **올리기 전에 꼭 직접 확인하세요.** 자동 검출은 작은 얼굴, 옆얼굴, 누운 얼굴, 마스크 쓴 얼굴을 놓칠 수 있습니다. 결과 영상을 처음부터 끝까지 본 뒤 게시하세요.

## 설치와 실행

Node.js 22 이상이 필요합니다.

```bash
npm install
```

```bash
npm run assets
```

```bash
npm run dev
```

- `npm run assets` 는 얼굴 검출 모델과 실행에 필요한 WASM 파일을 `public/` 아래로 받습니다. 저장소에는 이 파일들이 들어 있지 않으므로 처음 한 번은 꼭 실행해야 합니다.
- `npm run dev` 를 실행한 뒤 터미널에 표시되는 주소를 크롬에서 엽니다.

### 배포용 빌드

```bash
npm run build:deploy
```

```bash
npm run preview
```

`dist/` 폴더가 배포본입니다. `SharedArrayBuffer` 를 쓰기 때문에 서버가 교차 출처 격리 헤더(COOP·COEP)를 보내야 합니다. Vercel 에 올리면 `vercel.json` 의 헤더·보안 정책(CSP) 설정이 그대로 적용됩니다.

### 시험

| 명령 | 내용 |
| --- | --- |
| `npm test` | 단위 테스트 |
| `npm run fixtures` | 시험 영상 만들기(공개 사진 합성) |
| `npm run e2e` | 분석 → 저장 파이프라인 |
| `npm run e2e:ui` | 화면 흐름 |
| `npm run e2e:spec` | 사양 점검 |
| `npm run e2e:split` | 영상 나누기 |
| `npm run e2e:review` | 검토·수정 |
| `npm run e2e:pwa` | 오프라인 동작, 외부 요청 0건 확인 |

화면 시험은 설치된 크롬을 씁니다. `e2e:ui`, `e2e:pwa` 는 형식 변환까지 확인하므로 아래의 ffmpeg.wasm 을 설치해야 모두 통과합니다.

## 개인정보 원칙

- 영상·얼굴 데이터를 네트워크로 보내지 않습니다. 분석 도구나 외부 CDN 도 쓰지 않습니다.
- 모델·WASM 파일은 모두 같은 도메인(`public/`)에서만 읽습니다.
- 배포본의 보안 정책(CSP)이 같은 도메인 밖으로의 연결을 브라우저 차원에서 막습니다.
- 원본 파일은 고치지 않고 항상 새 파일로 저장합니다.
- 실제 학생 영상은 저장소에 넣지 않습니다.

## 알려진 한계

- 처리 속도는 컴퓨터 성능에 크게 좌우됩니다(개발 노트북 기준 1080p 5분 영상에 영상 길이의 약 3배).
- 90° 가까이 누운 얼굴은 찾지 못합니다.
- 모자이크 모양은 픽셀 모자이크 한 가지입니다.
- 검출 기준값과 기본 설정은 합성 시험 영상으로 정한 초안입니다. 실제 영상에 맞춰 조정이 필요할 수 있습니다.

## 직접 설치해야 하는 항목 (라이선스 안내)

아래 두 가지는 라이선스 조건 때문에 **이 저장소, 기본 설치(`npm run assets`), 기본 배포본에 넣지 않았습니다.**
필요한 분이 조건을 확인한 뒤 직접 설치해 주세요. 설치하지 않아도 MP4·MOV·WebM 영상의 얼굴 모자이크는 그대로 됩니다.

### 1. 형식 변환 기능 — ffmpeg.wasm 실행 파일 (GPL)

- **무엇인가**: AVI·MKV·WMV·MTS 처럼 브라우저가 바로 열지 못하는 영상을 MP4 로 바꿔 주는 실행 파일(`@ffmpeg/core` 0.12.10, x264 포함)입니다.
- **넣지 않은 이유**: **GPL-2.0-or-later** 라이선스입니다. 이 파일을 포함해 앱을 배포하면, 배포하는 사람에게 GPL 의무(라이선스 고지, 해당 소스 코드 제공 등)가 생깁니다.
- **없으면**: 위 형식의 파일을 열 때 “형식 변환 기능이 들어 있지 않습니다”라는 안내가 나옵니다. 다른 프로그램으로 MP4 로 바꿔서 불러오면 됩니다.
- **직접 설치하기**:

```bash
npm run assets:ffmpeg
```

  이 명령은 npm 에서 `@ffmpeg/core` 를 받아 `public/wasm/ffmpeg/` 에 넣습니다. 그 뒤 `npm run dev` 나 `npm run build` 를 하면 변환 기능이 켜집니다.
- **주의**: 자신의 컴퓨터에서만 쓰는 것은 문제가 없습니다. 이 파일을 넣은 채로 **다른 사람에게 배포(웹에 게시 포함)하려면 GPL 조건을 직접 확인하고 지켜야 합니다.** 학교·기관에서 쓸 때는 기관 기준도 확인하세요.
- **배포본에 넣으려면**: `npm run build:deploy` 는 이 파일을 넣지 않습니다. 넣으려면 `npm run assets:ffmpeg` 를 먼저 실행한 뒤 `npm run build` 로 빌드하세요.

### 2. SCRFD 얼굴 검출 모델 (사용 조건 미확인)

- **무엇인가**: 개발용 모델 비교 화면(`npm run dev` 후 주소 끝에 `?bench`)에서 YuNet 과 견줘 보려고 쓴 모델입니다. **앱 자체는 이 모델을 쓰지 않습니다**(앱은 MIT 라이선스의 YuNet 을 씁니다).
- **넣지 않은 이유**: HuggingFace 미러에서 받는 파일이라 사용 조건의 근거를 확인하지 못했습니다. 원본인 InsightFace 는 사전 학습 모델을 비상업 연구 목적으로 제한한다고 알려져 있습니다.
- **직접 설치하기** (모델 비교가 필요한 개발자만):

```bash
npm run assets:scrfd
```

- **주의**: 사용 조건을 직접 확인한 뒤 쓰세요. 배포본에는 넣지 마세요(빌드할 때 자동으로 빠집니다).
